# Raw Dataset

The original public parking-violations CSV is stored here:

- `parking_violations.csv` — original source file, retained unchanged.

The file contains 89,078 data rows and 31 columns. Dataset source, licence, record grain and data-quality checks are documented in [the dataset card](../dataset_card.md).

Do not overwrite the raw file with cleaned or sample data. Phase IV cleaning and loading should use separate staging/processed files or database staging tables.
